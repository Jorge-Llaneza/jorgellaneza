📋 Formulas & recipes

Average read time (cache + main memory + disk): t = Ac·tc + (1−Ac)·[ Ap·B·tp + (1−Ap)·td ]. With Ap = 1: Ac·tc + (1−Ac)·B·tp. B = words per cache block; td is per block.
Write-through (simple model): write hit = tp; write miss without allocate = tp; with allocate = block fetch (as a read miss) + tp. Mean = %reads·tr + %writes·tw.
Cost = Σ size(MiB) × price(€/MiB).
Cache geometry: lines = size / block; sets = lines / ways (DM: ways = 1, FA: sets = 1); offset = log₂ block; index = log₂ sets; tag = address bits − index − offset; memory blocks = 2address bits / block.
Hit/miss recipe: block = address ÷ block size; set = block mod sets; tag = block ÷ sets. Hit if a valid line of the set has that tag. On a miss with a full set replace the LRU line; if it is dirty (write-back) its block is updated in memory. Dirty blocks still cached at the end are not updated.
Paging: offset = log₂ page; virtual pages = 2(virtual bits − offset) = page-table entries; frames = 2(physical bits − offset); page table size = entries × bytes per entry; physical address = frame ‖ offset. Present = 0 with disk location → recoverable fault; no storage → fatal fault.
V/P cache without synonyms: cache size ≤ page size × ways.
MESI: read miss → E (no other copy) or S (others → S; an M owner writes back first); write → M and the others I (an M owner writes back first); write hit on S invalidates the others; E → M silently.
Conventions in this lab: addresses are of one addressable unit (bytes unless the exercise says words); one access per element in loop exercises; a miss costs tp (single access) or block×tp as selected in the Cache lab; “blocks updated” = blocks written to memory (write-backs of dirty replaced lines, or every write in write-through).
